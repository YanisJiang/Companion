# 状态驱动人设：性格维度与反应策略

## 目标

把「要不要动、什么语气」从散落闸门，收成：

```text
性格（慢变量）+ 生理/情境状态（快变量）→ 行为意图 → 模型只填文案
```

解决：闸门后期变乱；危机后仍可能冒日常碎念等「不像同一个人」的问题。

## 方案选择

采用 **状态驱动策略**（已确认）：

- 不采用「每拍让模型做总决策」为主路径（贵、飘、难测）。
- 不继续无限制堆闸门。
- 现有冷静窗 / 额度 / idle / 未回 streak / presence·life·silence 逐步**收编**为状态字段或意图表，而非推倒重来。

## 性格维度（慢变量，已限定）

共 **5** 维，取值 **0～1**。写入配置/种子，极少改；**不**进每日剧情文案。

| 键 | 中文 | 含义 | 主要影响 |
|---|---|---|---|
| `cling` | 黏人度 | 安静久了想不想你；被冷落后还敢不敢再冒 | 社交欲上涨速度；未回后是否易到 `silence` |
| `chatter` | 碎嘴度 | 主动/闲聊偏在场一句还是生活碎念 | `presence` vs `life`；拆泡意愿 |
| `heavySensitivity` | 沉重敏感 | 沉重话题后有多「收着」 | 危机残留时长；禁 `life` 强度 |
| `reserve` | 慢热/话少 | 烦或累时话收多紧 | 低精力 → 短回；差心情 → 少主动 |
| `chronotype` | 作息偏置 | 昼夜精力/社交基线（高=更夜猫） | 与时刻表叠：晚高早低 |

### 本角色默认值（恋人向，对齐现 persona/dossier）

| 键 | 默认 |
|---|---|
| `cling` | 0.7 |
| `chatter` | 0.65 |
| `heavySensitivity` | 0.8 |
| `reserve` | 0.55 |
| `chronotype` | 0.75（夜猫） |

### 明确不进性格维

| 内容 | 归属 |
|---|---|
| 口味、咖啡、爱好细节 | `character_dossier` 文案 |
| 异地软接、禁客服腔、禁找袜子借口 | 硬约束（persona 规则） |
| 今日心情、未完线、当日时刻表 | 快变量 / 既有模块输入 |

## 快变量（生理/情境）

一期建议最少 4 个（均可 0～1 或带截止时间戳）：

| 键 | 含义 | 主要输入 |
|---|---|---|
| `energy` | 精力 | 时段 + chronotype；连聊消耗；空闲回升 |
| `mood` | 心情 | 对话基调；可与 `today` 心情对齐 |
| `socialDrive` | 社交欲 | 安静时长 × cling 上涨；主动发出/用户未回则下降 |
| `crisisResidue` | 危机残留 | 沉重话题触发；衰减时长 × heavySensitivity |

可选后续再加：`busyness`（接 clock）、`threadPull`（接 continuity 权重）。

## 行为意图（策略输出）

`decide(state, traits) → intent`，枚举建议：

| 意图 | 含义 | 典型约束 |
|---|---|---|
| `silence` | 不主动 | 不调模型 |
| `presence` | 在场一句 | 短、禁生活碎念清单 |
| `life` | 生活碎念 | 需 energy/mood 尚可且 crisis 低 |
| `check_in` | 轻接未完线/牵挂 | 有 continuity 时抬权 |
| `heavy_hold` | 沉重冷静陪伴 | 禁 `life`；少问少方案 |
| `reply_normal` | 正常回用户 | 被动链默认 |
| `reply_soft` | 低精力/忙碌短回 | energy 低或 reserve 生效时 |

映射原则（实现时落成纯函数 + 单测，数值可调）：

- `crisisResidue` 高 → 只允许 `heavy_hold` / `silence`（及被动的克制回），禁止 `life`
- `socialDrive` 高 + `energy` 尚可 + 无危机 → 可 `life` / `check_in`
- `energy` 低 → 被动偏 `reply_soft`；主动最多 `presence`
- `chatter` 高更易从 `presence` 升到 `life`
- `cling` 低 + 未回多 → 更快 `silence`（替代「硬编码最多再冒 1 次」的观感来源；可暂留安全帽）

## 与模型的分工

1. **策略**：是否主动、意图档位、可否拆泡。
2. **模型**：在给定意图 + 人设 + 今日/未完线/记忆下生成文案。
3. System / 主动 prompt 须显式带上当前意图与关键快变量摘要，避免模型自作主张改档。

## 与现有模块对照（收编，非一夜删除）

| 现有 | 收编方向 |
|---|---|
| `crisis` 冷静窗 | → `crisisResidue` |
| `initiative-context` 语气与未回 streak | → 意图枚举 + 扣 `socialDrive` |
| `followup` idle 窗 / 日额度 | → `socialDrive` 阈值与耗尽；可留粗安全帽防刷屏 |
| `today` / `clock` / `continuity` | → 写入或调制快变量；文案仍可注入 prompt |
| `persona` / dossier | → 硬约束 + 文案；性格五维另存配置 |
| `rhythm` 安静窗回 | → 被动链可保留确定性回合；意图只约束语气/长度 |

## 不做（本设计范围）

- 完整打工/地图人生模拟
- 每拍 LLM 总决策 Agent
- 情绪面板大 UI（设置里只读状态可选，非必须）
- 把口味等档案细节做成决策滑杆

## 验收（设计级）

- 性格仅 5 维，有默认值表，可单测「同状态不同系数 → 不同意图」
- 沉重话题后一段时间内，策略层禁止 `life`（不依赖模型自觉）
- 主动找你路径：先 `decide` 再生成；`silence` 不调模型
- 文档与实现计划能指回本表，不平行再堆无名闸门
